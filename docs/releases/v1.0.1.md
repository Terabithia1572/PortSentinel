# PortSentinel 1.0.1 — Windows 10/11 x64

**Geliştirici: Yunus İNAN — Terabithia1572**

Türkçe WPF arayüzü, ayrı Windows Worker Service, SQLite kalıcılığı ve Windows token'ıyla yetkilendirilmiş Named Pipe iletişimi içeren cihaz izin yönetimi/keşif sürümü.

## İndirme

- `PortSentinel-Setup-1.0.1.exe`: .NET 10.0.12 x64 çalışma zamanını içeren tek kurulum EXE'si. .NET ayrıca kurulmaz.
- `PortSentinel-Setup-1.0.1.sha256`: EXE bütünlük kontrol özeti.
- `verification-1.0.1.json`: build/paket ve yerel doğrulama özeti; özel dosya yolu/token içermez.
- GitHub'ın Source code arşivleri: kaynaklar, migration, testler, build/kurulum betikleri ve belgeler.

## Bu sürümde

Windows 10/11 x64 için Home/Pro/Enterprise/Education, 24H2/25H2 güncelleme adı ve destek tarihi kurulum engelleri kaldırıldı. Windows 11 Pro 23H2 mevcut makinedeki gerçek Windows PowerShell ön kontrolünden geçti. Türkçe modern sihirbaz, isteğe bağlı masaüstü kısayolu, LocalService Windows servisi ve Yunus İNAN yayıncı/copyright bilgileri korunur.

Kaynak deposunda ekran görüntüleri, mimari/IPC belgeleri, kurulum/kurtarma açıklamaları, değişiklik günlüğü, issue/PR şablonları ve Windows CI bulunur. Setup dosyaları kaynak Git geçmişine dahil edilmez; bu sürüm varlıkları olarak dağıtılır.

## Kullanım

Setup'ı yönetici yetkisiyle çalıştırın, ardından Başlat menüsünden PortSentinel'i açın. Standart kullanıcı görüntüleyebilir; yönetim işlemleri için “Yönetici olarak aç” kullanılır. Program Files altında service/desktop, ProgramData altında SQLite ve loglar oluşturulur. Kaldırmada servis/dosyalar kaldırılır, veritabanı/ayar/audit korunur. Yerinde yükseltme yoktur; önce mevcut sürümü kendi kaldırıcısıyla kaldırın.

## Doğrulama

Release build 0 hata/uyarı; 24 unit + 18 integration = 42 başarılı test. Gerçek Windows pipe/token ve salt okunur CIM/Defender adaptörleri çalıştırıldı. Self-contained servis ve WPF geliştirme smoke testi geçti; beş ekran render edildi, binding hatası yok. Paket SHA256 manifesti ve PowerShell sözdizimi doğrulandı.

Windows 10 üzerinde ayrı çalıştırma testi ve gerçek SCM kurulum/kaldırma/yeniden başlatma kabulü henüz yapılmadı. GitHub Actions kendi build/test sonuçlarını ayrıca raporlar; Windows runner sonucu tüm gerçek cihaz senaryolarını doğrulamaz.

## Ürün sınırı

**Bu sürüm fiziksel USB dosya erişimini engellemez.** İzin eklemek veya iptal etmek Windows erişim politikasını etkinleştirmez. USBSTOR/Defender/GPO/MDM politikaları değiştirilmez. Lisanslı Defender Device Control entegrasyonu, politika sahipliği/readback/geri alma ve USBSTOR/UASP/boot/handle donanım kabulü bekler. EXE kod imzalı değildir.
