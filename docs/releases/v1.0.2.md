# PortSentinel 1.0.2 — Kurulum ve servis düzeltmeleri

**Geliştirici: Yunus İNAN — Terabithia1572**

1.0.1'de servis kurulmadan setup'ın başarılı görünmesine, arayüzde bağlantı zaman aşımına, `ProgramData bulunamadı` kaldırma hatasına ve kalan dizin yüzünden tekrar kurulumun engellenmesine neden olan hatalar düzeltildi.

## Kurulum

PortSentinel pencerelerini kapatın ve **PortSentinel-Setup-1.0.2.exe** dosyasını yönetici olarak çalıştırın. Eski 1.0.1 kaldırıcıyı önce çalıştırmanız veya klasörleri elle silmeniz gerekmez. Setup sahipliği doğrulanmış yarım/eski kurulumu onarır; mevcut veritabanı, ayarlar ve kayıtları korur.

Windows 10/11 x64 hedefi, Türkçe sihirbaz ve Yunus İNAN geliştirici bilgileri korunur. .NET 10.0.12 x64 çalışma zamanı pakettedir.

## Düzeltmeler

- Windows PowerShell 5.1 JSON manifesti doğru okunur; `ChildPath` dizi hatası giderildi. Sistem modülleri PowerShell'in kendi dizininden yüklenir.
- Kritik işlemler Inno `PrepareToInstall` kapısında tamamlanır; servis/SCM PID ve gerçek IPC yanıtı doğrulanmadan setup ilerlemez.
- Restart Manager yeni servisi kurulum sonunda durdurmaz. Binary yolu SCM API'siyle tırnaklı kaydedilir.
- Eksik ProgramData/receipt, paket işareti ve hash manifestiyle doğrulanmış kaldırmayı engellemez. Boş dizinler temizlenir; bilinmeyen/değişmiş dosyalar korunur.
- Servis ilk uzun cihaz taramasından önce IPC dinlemeye başlar; bağlantı hataları Türkçe kurtarma bilgisi gösterir.
- LocalService'in okuyamadığı registry anahtarları diğer tanılamaları kaybettirmeden raporlanır.

## Doğrulama

Release build 0 hata/uyarı; **42 .NET testi + 10 Windows PowerShell 5.1 regresyonu** başarılı. Windows 11 Pro 23H2/build 22631 üzerinde gerçek temiz kurulum, eski/çalışan servisi onarım, kaldırma, DB/bilinmeyen dosya koruma, tekrar kurulum ve ProgramData eksikken kaldırma çalıştırıldı. LocalService altında üretim SCM PID/IPC ve beş WPF ekranı doğrulandı; binding logu 0 byte.

Windows CI'a gerçek kurulum yaşam döngüsü kabulü eklendi. Windows 10 üzerinde ayrı çalıştırma, reboot ve USB donanım kabulü bu kapsamda yapılmadı.

## Dosyalar ve kapsam

- `PortSentinel-Setup-1.0.2.exe`: kurucu.
- `PortSentinel-Setup-1.0.2.sha256`: bütünlük özeti.
- `verification-1.0.2.json`: makineye özel yol/token içermeyen doğrulama özeti.

Bu sürüm cihaz izin yönetimi/keşif sürümüdür; **fiziksel USB dosya erişimini engellemez**. USBSTOR/Defender/GPO/MDM politikaları değiştirilmez. EXE kod imzalı değildir.
